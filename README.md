# Флёр — интернет-магазин цветов

Интернет-магазин цветочной мастерской: каталог с фильтрами, корзина, оформление
заказа с имитацией онлайн-оплаты и полноценная админ-панель, в которой владелец
сам управляет товарами и заказами.

Проект написан на **Next.js 16 (App Router)** с серверными компонентами и
Server Actions, базой данных через **Prisma**, стилями на **Tailwind CSS v4**.
Адаптивен под мобильные, поддерживает светлую и тёмную темы.

---

## Возможности

### Витрина (публичная часть)
- Главная страница с популярными товарами и категориями
- Каталог с фильтром по категориям и сортировкой по цене
- Страница товара с описанием и похожими товарами
- Корзина (сохраняется в браузере) с изменением количества
- Оформление заказа: доставка + **имитация оплаты картой** или оплата при получении
- Страницы «О нас» и «Контакты»
- SEO-метаданные, адаптивная вёрстка, светлая/тёмная тема

### Админ-панель (`/admin`)
- Вход по паролю
- Обзор: количество товаров, заказов, сумма
- Управление товарами: создание, редактирование, удаление
- Управление категориями: создание, переименование, порядок, удаление
- Список заказов с контактами клиента и сменой статуса (новый → в работе → выполнен)

## Быстрый старт (локально)

Нужен установленный **Node.js 20+** и облачная база PostgreSQL
(бесплатный **Neon** — см. раздел «Деплой»). Локальный Postgres ставить
не нужно: разработка идёт с той же облачной базой.

```bash
# 1. Установить зависимости
npm install

# 2. Прописать строку подключения к базе в .env
cp .env.example .env
# затем открыть .env и вставить DATABASE_URL из Neon

# 3. Применить схему к базе
npx prisma migrate deploy

# 4. Наполнить базу демо-товарами
npm run seed

# 5. Запустить в режиме разработки
npm run dev
```

Сайт откроется на http://localhost:3000

### Доступ в админку
- Адрес: http://localhost:3000/admin
- Пароль по умолчанию: `admin123` (задаётся в `.env`, переменная `ADMIN_PASSWORD`)

## Переменные окружения (`.env`)

| Переменная       | Назначение                                        |
| ---------------- | ------------------------------------------------- |
| `DATABASE_URL`   | Строка подключения к PostgreSQL, вид `postgresql://…` (Neon) |
| `ADMIN_PASSWORD` | Пароль для входа в админ-панель                    |
| `AUTH_SECRET`    | Секрет для подписи cookie сессии (в проде заменить на случайную строку) |

## Деплой на Vercel

Проект уже настроен на облачный **PostgreSQL**. На Vercel (бессерверная среда)
нужна именно облачная база — проще всего бесплатный **Neon**. Шаги:

1. **Завести облачную базу Neon** (https://neon.tech) и скопировать строку
   подключения (`postgresql://...`).

2. **Загрузить код в GitHub** (создать репозиторий и запушить проект).

3. **Импортировать репозиторий в Vercel** (New Project → выбрать репозиторий).

4. **Добавить переменные окружения** в настройках проекта Vercel:
   `DATABASE_URL`, `ADMIN_PASSWORD`, `AUTH_SECRET`.

5. **Применить миграции и наполнить базу** (один раз, локально с прод-строкой
   подключения — она уже лежит в `.env`):
   ```bash
   npx prisma migrate deploy
   npm run seed
   ```

6. Vercel соберёт проект и выдаст рабочий адрес вида `flower-shop.vercel.app`.

> Клиент Prisma генерируется автоматически при сборке (`prisma generate` в
> скрипте `build`), поэтому отдельных действий не требуется.

## Про оплату

Онлайн-оплата реализована как **имитация** (демо): форма ввода карты и экран
«платёж прошёл успешно», без обращения к реальному платёжному сервису.
Чтобы принимать настоящие платежи, подключается платёжный сервис (например,
ЮKassa): сначала в тестовом режиме, затем в боевом — после того как владелец
магазина оформит ИП/ООО и пройдёт проверку. Это отдельный шаг на стороне
владельца, не влияющий на текущую разработку.

## Про изображения

Изображения товаров — сгенерированные иллюстрации-заглушки в едином стиле
(см. `scripts/gen-images.mjs`). В боевом магазине они заменяются на реальные
фотографии товаров, которые предоставляет владелец.
